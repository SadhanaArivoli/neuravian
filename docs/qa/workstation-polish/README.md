# Workstation polish visual QA

This directory contains representative before-and-after screenshots from the
professional workstation polish milestone. The images cover the shared NIfTI
viewer, workflow graph, run results, pipeline configuration, and study report
surfaces at desktop and small-laptop viewport sizes.

The `before-*` captures were taken from the existing Docker-served production
bundle before rebuilding it with this milestone. The `after-*` captures were
taken after the production rebuild from the same historical dataset and runs.
